# 数字人灵动化实现报告

## 概述

将原有 mock 占位的数字人组件替换为基于 **pixi-live2d-display** 的真实 Live2D 渲染，实现类似"小慧 AI 助手"的可交互数字人体验。

## 实现内容

### 1. 真实 Live2D 模型渲染

**文件**: `src/components/DigitalHuman/Live2DStage.tsx`

- 使用 `PIXI.Application` + `Live2DModel.from()` 加载 `.model3.json` 模型
- 透明背景，自适应容器尺寸
- 鼠标跟踪：模型眼睛/头部跟随鼠标移动（`model.focus()`）
- 点击触发随机动作（`TapBody`/`TapHead`）
- 通过 `forwardRef` + `useImperativeHandle` 暴露模型操作接口

### 2. Idle 动画系统

**文件**: `src/hooks/useIdleAnimation.ts`

- **自动眨眼**: 2.5-6秒随机间隔，120ms 眨眼时长
- **呼吸效果**: 4秒周期的微身体摆动（`ParamBodyAngleX/Y/Z`）
- 说话时自动暂停 idle 动画，避免动作冲突

### 3. 表情控制器

**文件**: `src/components/DigitalHuman/EmotionController.tsx`

- 情绪映射: `positive→happy`, `negative→sad`, `neutral→default`, `surprised→surprised`, `thinking→thinking`
- 自动重置: 非 neutral 情绪 5秒后自动回到 default
- 纯逻辑组件，不渲染 DOM

### 4. 口型同步

**文件**: `src/components/DigitalHuman/LipSync.tsx`

- 音频 RMS 计算 → 归一化 → 平滑处理
- 驱动 `ParamMouthOpenY` 和 `ParamMouthForm` 参数
- 无音频时自动闭嘴（带衰减过渡）

### 5. 数字人聚合组件

**文件**: `src/components/DigitalHuman/DigitalHuman.tsx`

- 整合 Live2DStage + EmotionController + LipSync + idle 动画
- 说话状态指示器（动态音量条 + "讲解中..."标签）
- 渐变背景装饰

### 6. 聊天页面集成

**文件**: `src/pages/tourist/ChatPage.tsx`

- 数字人显示在聊天区域上方（类小慧布局）
- AI 回复时自动检测情绪并切换表情
- 回复完成后模拟 TTS 说话状态
- 支持移动端响应式布局

### 7. 管理后台预览

**文件**: `src/pages/admin/AvatarPage.tsx`

- 预览区域从静态图标替换为实时 Live2D 数字人

## 架构对比

| 对比项 | 小慧 AI 助手 | 本项目 |
|--------|-------------|--------|
| 形象技术 | Unity WebGL (50MB+) | Live2D (2-5MB) |
| 渲染引擎 | Unity | pixi.js v7 |
| 模型格式 | Unity 3D | Cubism 4 (.moc3) |
| 口型同步 | 百度 TTS + Unity | Web Audio API + Live2D 参数 |
| 表情控制 | Unity Animator | Live2D Expression |
| 集成方式 | iframe + SendMessage | React 组件 + ref |

## 使用方式

### 下载模型文件

```bash
cd frontend
node scripts/download-model.cjs
```

该脚本会下载免费的 Haru Greeter 示例模型到 `public/models/haru/`。

### 自定义模型

将任意 Cubism 4 模型（`.model3.json`）放入 `public/models/` 目录，然后修改 `DigitalHuman.tsx` 中的 `DEFAULT_MODEL` 常量：

```tsx
const DEFAULT_MODEL = '/models/your-model/your-model.model3.json';
```

### 启动开发服务器

```bash
npm run dev
```

访问首页即可看到数字人在聊天页面上方。
