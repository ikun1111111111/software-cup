# 模块 B 技术文档：数字人体验

## 概述

模块 B 实现了智慧旅游数字人导览系统的核心交互体验，包括 Live2D 数字人渲染、TTS 流式语音合成、口型同步、表情控制、悬浮助手、语音交互、离线缓存、方言/形象切换等功能。

**技术栈：** React 19 + TypeScript + Vite + pixi-live2d-display (Cubism 4) + PIXI.js v7

## 核心组件

### 1. DigitalHuman — 数字人聚合组件

**文件：** `src/components/DigitalHuman/DigitalHuman.tsx`

数字人的顶层组件，整合了 Live2D 渲染、表情控制、口型同步、音频播放等所有子模块。

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `modelPath` | `string` | `'/models/haru/...'` | Live2D 模型文件路径 |
| `width` | `number` | `320` | 画布宽度 |
| `height` | `number` | `400` | 画布高度 |
| `emotion` | `Emotion` | `'neutral'` | 当前表情 |
| `expression` | `string \| null` | `null` | 直接指定 Live2D 表情名（如 `'f00'`），优先于 emotion |
| `audioChunks` | `string[]` | `[]` | 流式音频数据（base64） |
| `phonemes` | `Phoneme[]` | `[]` | 音素时间戳数组 |
| `isSpeaking` | `boolean` | `false` | 是否正在说话 |
| `onReady` | `() => void` | - | 模型加载完成回调 |

### 2. Live2DStage — Live2D 渲染层

**文件：** `src/components/DigitalHuman/Live2DStage.tsx`

基于 `pixi-live2d-display/cubism4` 的 Live2D 模型渲染组件。

**功能：**
- 通过 `Live2DModel.from()` 加载 `.model3.json` 模型
- 透明背景，自适应容器尺寸
- 鼠标跟踪：模型眼睛/头部跟随鼠标移动
- 点击触发随机动作（TapBody/TapHead）
- 通过 `forwardRef` + `useImperativeHandle` 暴露模型操作接口

### 3. LipSync — 口型同步

**文件：** `src/components/DigitalHuman/LipSync.tsx`

支持两种驱动模式，自动降级：

**模式一：音素时间戳驱动（优先）**
```
Phoneme[] → 逐帧匹配当前播放时间 → 设置 ParamMouthOpenY / ParamMouthForm
```

每个音素包含：
- `char`：对应字符
- `start_ms` / `end_ms`：毫秒级起止时间
- `mouth_shape`：`"closed"` | `"half"` | `"open"`

**模式二：WebAudio 频谱分析（降级）**
```
AnalyserNode → 频率数据 → RMS 计算 → 归一化 → ParamMouthOpenY
```

两种模式都会附加 `ParamAngleZ` 让头部随说话节奏轻微左右摆动。

### 4. EmotionController — 表情控制器

**文件：** `src/components/DigitalHuman/EmotionController.tsx`

**五种表情类型（业务语义）：**

| Emotion | 含义 | Live2D 参数组合 |
|---------|------|-----------------|
| `smile` | 微笑 | ParamEyeLOpen=0.8, ParamMouthForm=1.0 |
| `think` | 思考 | ParamEyeBallX=-0.3, ParamAngleZ=-10 |
| `sorry` | 抱歉 | ParamEyeLOpen=0.5, ParamBrowLY=-0.5 |
| `surprise` | 惊喜 | ParamEyeLOpen=1.0, ParamMouthOpenY=0.6 |
| `neutral` | 中性 | 所有参数归零 |

表情切换时有 300ms 渐变过渡，不会生硬跳变。

### 5. AudioSync — 音频同步

**文件：** `src/components/DigitalHuman/AudioSync.tsx`

接收 `audioChunks` prop（base64 字符串数组），解码为二进制，拼接成 Blob，创建 Blob URL 交给 Audio 元素播放。播放过程中持续把当前时间（毫秒）同步给 LipSync。

### 6. VoiceInput — 语音输入

**文件：** `src/components/DigitalHuman/VoiceInput.tsx`

**交互设计：**
- 长按 300ms 触发录音，短按不误触发
- 鼠标离开取消长按
- 支持触摸和鼠标事件

**新增功能：**
- **语速调节：** 设置按钮 → 0.5x ~ 2x 滑块，保存到 localStorage
- **打断功能：** 按下语音按钮时触发 `onInterrupt` 回调
- **实时转写：** 录音中显示 ASR 识别文字

### 7. FloatingAssistant — 全局悬浮助手

**文件：** `src/components/DigitalHuman/FloatingAssistant.tsx`

全局挂载的数字人交互入口，不依赖路由。

**设计细节：**
- 可拖拽悬浮球，固定在屏幕右下角，48px 大小
- 点击展开 340px 宽的对话面板（消息列表 + 输入框 + 语音按钮）
- 新消息弹跳动画（150ms）+ 红点提示
- `Ctrl+K` 快捷键切换面板
- 监听 `entity:click` 事件，点击景点时自动展开

## 服务层

### offlineCache — 离线缓存服务

**文件：** `src/services/offlineCache.ts`

基于 IndexedDB 的离线数据缓存，用于网络不佳时提供基本导览服务。

**数据库：** `lingshan_offline`，版本 1

**三个 Store：**

| Store | 存储内容 | 示例字段 |
|-------|---------|---------|
| `qa_pairs` | 问答对 | `{ q: "灵山大佛有多高？", a: "通高88米。" }` |
| `scenic_spots` | 景点信息 | `{ id, name, description, lat, lng, duration }` |
| `meta` | 元数据 | `{ version, cached_at, entry_count }` |

**核心函数：**

| 函数 | 说明 |
|------|------|
| `cachePackage(pkg)` | 将离线包数据写入 IndexedDB |
| `getCachedQA()` | 获取所有缓存的问答对 |
| `getCachedSpots()` | 获取所有缓存的景点 |
| `getCacheMeta()` | 获取缓存元数据 |
| `hasCache()` | 检查是否有缓存数据 |
| `searchCachedQA(keyword)` | 基于关键词的本地搜索 |
| `syncOfflinePackage()` | 从服务器拉取并缓存离线包（支持 ETag） |
| `getNetworkMode()` | 返回 `'online'` 或 `'offline'` |
| `onNetworkChange(cb)` | 监听 online/offline 事件 |

## 配置

### avatarModels — 模型映射

**文件：** `src/config/avatarModels.ts`

```ts
export const MODEL_MAP: Record<string, string> = {
  'model-1': '/models/haru/haru_greeter_t03.model3.json',
  'model-2': '/models/haru/haru_greeter_t03.model3.json',
  'model-3': '/models/haru/haru_greeter_t03.model3.json',
};

export function getModelPath(modelId: string): string {
  return MODEL_MAP[modelId] || MODEL_MAP['model-1'];
}
```

添加新模型：将 `.model3.json` 放入 `public/models/<name>/`，在 `MODEL_MAP` 中添加映射即可。

## 后端 API

### TTS 流式接口

**`POST /api/tts/stream`** — SSE 流式语音合成

请求：`{ text: string, voice?: string }`

响应：SSE 事件流，每个事件包含：
```json
{
  "audio_chunk": "<base64 音频数据>",
  "phonemes": [
    { "char": "你", "start_ms": 0, "end_ms": 250, "mouth_shape": "half" }
  ],
  "is_last": false
}
```

**`GET /api/tts/voices`** — 获取可用语音列表

**`POST /api/tts/cache`** — 查询文本是否已缓存

### 离线包接口

**`GET /api/offline/package`** — 下载离线包（支持 ETag/If-Modified-Since）

**`GET /api/offline/status`** — 查询离线包状态

### 方言支持

三种预置语音：`mandarin`（普通话）、`nanjinghua`（南京话）、`sichuanhua`（四川话）

通过 `voice` 参数切换，不同方言对应不同的 CosyVoice speaker_id。
