把 emoji 和临时字标，换成灵山自己的视觉语言

这个 demo 不改正式页面，只演示素材上屏后的气质：首屏用寺院庭院和山水做沉浸背景， 功能入口从“相 / 签 / 路 / 问”变成可识别的图像标记，打卡和底部导航也统一成印章、 地图、卷轴这一套语汇。数字人放在首屏中景右侧，真实接入时这里就是移动端的 VRMView。

保留文字，不把操作图片化

“开始游览”“问小灵”“查看路线”仍然是文字，图片只负责建立记忆点和语境。

功能入口用真实素材裁切

识景用佛像局部，打卡用唐/灵山印章，路线用古地图，问询用灯笼做陪伴感。

底部 Tab 不再依赖系统 emoji

不同设备上的 emoji 风格差异很大，换成项目素材后更像一套完整产品。

后续可再补一套线性 icon

相机、二维码、多人协同这些现代功能，最好单独画一套细线图标，和素材混用。
