# 旅行记忆册 — 实现文档

## 概述

旅行记忆册从游客与 AI 导游的对话中自动提取旅行记忆，支持 AI 润色、旅程总结、分享卡片导出。

## 架构

```
ChatPage / VisionPage / RecommendPage  →  interaction_logs (session_id)
                                                    ↓
                                          memory_service.extract_memories_from_chat()
                                                    ↓  LLM 提取
                                          travel_memories 表
                                                    ↓
                                    ┌───────────────┼───────────────┐
                                    ↓               ↓               ↓
                              AI 润色         旅程总结         分享卡片
                           (polish)      (summary)       (html-to-image)
```

## 后端

### 数据模型

| 表名 | 模型 | 说明 |
|------|------|------|
| `travel_memories` | `TravelMemory` | 单条旅行记忆 |
| `journey_summaries` | `JourneySummary` | 旅程总结 |

**TravelMemory 字段:**
- `session_id` — 关联游客会话
- `title` — 记忆标题
- `original_content` — 原始内容
- `polished_content` — AI 润色后内容
- `spot_name` / `spot_id` — 关联景点
- `source_type` — 来源: chat / vision / route
- `mood_tag` — 情绪标签: 敬畏/惊喜/平静/感动/愉悦
- `metadata_json` — 扩展数据

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/memory/list?session_id=xxx` | GET | 获取所有记忆 |
| `/api/memory/generate` | POST | 从对话提取记忆 |
| `/api/memory/{id}/polish` | POST | AI 润色单条 |
| `/api/memory/summary/generate` | POST | 生成旅程总结 |
| `/api/memory/summary/latest?session_id=xxx` | GET | 获取最新总结 |

### 关键文件

- `backend/app/models/memory.py` — 数据模型
- `backend/app/services/memory_service.py` — 记忆服务
- `backend/app/api/memory.py` — API 路由

## 前端

### 页面

### 组件

- `components/Memory/ShareCard.tsx` — 分享卡片 (水墨风格, html-to-image 导出)

- `src/api/memory.ts` — TypeScript 接口和 API 函数

### Session 管理

使用 `localStorage` 持久化 `tourist_session_id`，确保跨页面记忆关联。

## 数据流

1. 游客在 ChatPage 与 AI 对话 → 记录到 `interaction_logs`
2. 进入 MemoryPage → 点击"从对话提取记忆"
3. 后端 LLM 分析对话，提取有价值的记忆片段
4. 可对单条记忆进行 AI 润色（古风散文风格）
5. 生成旅程总结（完整游记）
6. 导出分享卡片为 PNG

## 依赖

- `html-to-image` — DOM 节点导出为 PNG
