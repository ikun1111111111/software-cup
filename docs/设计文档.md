# 灵山胜境 AI 数字人智慧导览系统 · 设计文档

## 1. 产品概述

### 1.1 项目名称
灵山胜境 AI 数字人智慧导览系统

### 1.2 项目定位
面向灵山胜境景区的 AI 驱动智能导览系统，为游客提供多模态交互（语音/文本）、个性化路线推荐、协同导览、拍照识景等服务，为管理方提供知识库管理、数据大屏、感受度报告等管理工具。

## 2. 功能设计

### 2.1 赛题七大功能

| 功能编号 | 功能名称 | 技术实现 |
|---------|---------|---------|
| F1 | 多模态交互 | 语音→ASR(faster-whisper)→LLM(DeepSeek/Qwen/Doubao)→TTS(CosyVoice)→Live2D口型/表情同步 |
| F2 | 智能问答 | RAG混合检索(Milvus + BM25 + BGE-Reranker) + LLM回答，准确率≥90% |
| F3 | 个性化推荐 | K-Means游客聚类 + 协同过滤推荐 + DNA画像 |
| F4 | 知识库管理 | 文档上传→Celery异步索引→Milvus向量化→检索生效 |
| F5 | 数字人管理 | Live2D外观切换 + 声音选择 + TTS音色配置 |
| F6 | 感受度报告 | 交互分析→情感趋势→LLM服务建议 |
| F7 | 数据大屏 | 实时监控 + 热门问答 + 满意度 + 客流热力图 |

### 2.2 创新功能（6项）

1. **AI数字人沉浸式导游** — 多角色系统（佛祖/禅师/游客/徐霞客视角）+ 情感自适应
2. **旅游DNA推荐** — K-Means聚类6-8个游客DNA类型 + 协同过滤推荐
3. **时空穿越体验** — Neo4j历史知识图谱 + 角色扮演讲解
4. **禅意冥想声音疗愈** — LLM冥想词生成 + 环境音混音 + 呼吸引导
5. **游客行为热力图预测** — Prophet时序预测 + 拥挤度API
6. **文化解谜游戏化** — AI动态谜题生成 + 数字印章 + 成就系统

### 2.3 串联功能（3项）

- **拍照识景→协同导览** — 拍照识别结果一键同步到协同房间行程
- **协同导览LLM问答** — 房间内AI导游回答对所有成员可见
- **推荐路线→房间推送** — AI推荐列表一键推送到房间行程

## 3. API 设计

### 3.1 对话服务
- `POST /api/chat/stream` — SSE流式对话
- `WebSocket /ws/chat` — 音频流双向通信
- `POST /api/chat/role` — 多角色切换

### 3.2 推荐服务
- `POST /api/recommend/routes` — AI个性化推荐
- `POST /api/recommend/dna` — DNA推荐
- `GET /api/recommend/dna/profile` — 用户DNA画像
- `POST /api/recommend/feedback` — 推荐反馈

### 3.3 协同房间
- `POST /api/room/create` — 创建房间
- `POST /api/room/{id}/join` — 加入房间
- `POST /api/room/{id}/itinerary/add-spot` — 添加景点
- `WebSocket /api/room/{id}/ws` — 房间实时通信

### 3.4 拍照识景
- `POST /api/vision/identify` — 拍照识别+讲解
- `POST /api/vision/sync-to-room` — 识别结果同步到房间

### 3.5 知识库管理
- `GET/POST /api/knowledge/docs` — 文档管理
- `GET/PUT/DELETE /api/knowledge/docs/{id}` — 文档操作
- `GET/POST/PUT/DELETE /api/knowledge/faq` — FAQ管理

### 3.6 分析服务
- `GET /api/analytics` — 统计指标
- `GET /api/analytics/sentiment` — 情感趋势
- `GET /api/analytics/crowd` — 拥挤度预测
- `GET /api/analytics/crowd/best-time` — 最佳时段推荐

## 4. 数据设计

### 4.1 行为数据模型
- 14万条游客行为记录（17维特征）
- K-Means聚类生成6-8个DNA类型
- 协同过滤计算用户相似度

### 4.2 知识图谱
- 20+景点节点 + 5朝代节点 + 历史事件 + 文化概念
- Neo4j图数据库存储
- 图查询增强RAG检索

## 5. 部署架构

### 5.1 Docker Compose 服务
```
services:
  backend (FastAPI + Uvicorn)
  frontend (Nginx + React)
  postgres (PostgreSQL 16)
  milvus (向量数据库)
  redis (缓存+队列)
  neo4j (知识图谱)
  celery-worker (异步任务)
```

### 5.2 环境变量
- LLM_API_KEYS: DeepSeek/Qwen/Doubao API密钥
- DATABASE_URL: PostgreSQL连接
- MILVUS_HOST: Milvus地址
- REDIS_URL: Redis连接
- NEO4J_URI: Neo4j连接
