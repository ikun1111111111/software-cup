| 测试集规模 | 100 题 |
| LLM 模型 | DeepSeek-V3 (主) / Qwen / Doubao (备) |
| RAG 管线 | Milvus 向量检索 + BM25 关键词 + BGE-Reranker 精排 |

## 评测方法

对每道测试题：
1. 调用 chat_service.process_chat() 获取回答
2. 检查回答中是否包含 expected_keywords 中的至少一个关键词
3. 命中任一关键词即判定为"正确"

## 错误分析

### 常见错误类型

1. **知识缺失** — RAG 语料中缺少相关信息
   - 解决：补充灵山胜境专属语料到知识库

2. **检索不准** — Milvus 返回的 chunk 不相关
   - 解决：调整 embedding 参数 + 增加 Reranker 阈值

3. **关键词未命中** — 回答语义正确但未使用期望关键词
   - 解决：优化 scoring 逻辑，增加同义词扩展

## 达标路径

如果准确率低于 90%：
1. 扩充 RAG 语料（景点讲解词、历史资料、FAQ）
2. 优化混合检索权重（BM25 vs 向量检索）
3. 调整 Reranker 精排 Top-K 参数
4. 增加 FAQ 白名单覆盖率
