# 灵山胜境 AI 数字人智慧导览系统 · 部署手册

## 环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Docker | ≥ 24.0 | 容器运行时 |
| Docker Compose | ≥ 2.0 | 容器编排 |
| Python | ≥ 3.11 | 本地开发 |
| Node.js | ≥ 18 | 前端开发 |
| PostgreSQL | 16 | 关系数据库 |
| Redis | 7 | 缓存/消息队列 |
| Milvus | 2.5+ | 向量数据库 |

## 一、Docker Compose 一键部署

### 1.1 克隆项目
```bash
git clone <repository-url>
cd 软件杯第一阶段
```

### 1.2 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 文件，填入 API Keys
vim .env
```

必填环境变量：
```
# LLM API Keys
DEEPSEEK_API_KEY=your_key
QWEN_API_KEY=your_key
DOUBAO_API_KEY=your_key

# Database
DATABASE_URL=postgresql+asyncpg://user:password@postgres:5432/lingshan
MILVUS_HOST=milvus
MILVUS_PORT=19530
REDIS_URL=redis://redis:6379/0
NEO4J_URI=bolt://neo4j:7687

# App
SECRET_KEY=your_secret
ENVIRONMENT=production
```

### 1.3 启动所有服务
```bash
docker-compose up -d
```

服务列表：
- `backend` — FastAPI 后端 (port 8000)
- `frontend` — React 前端 (port 5173)
- `postgres` — PostgreSQL (port 5432)
- `milvus` — 向量数据库 (port 19530)
- `redis` — Redis (port 6379)
- `neo4j` — 知识图谱 (port 7687)
- `celery-worker` — 异步任务

### 1.4 初始化数据
```bash
# 初始化数据库表
docker-compose exec backend python -m alembic upgrade head

# 导入景点数据
docker-compose exec backend python scripts/seed_lingshengjing.py

# 导入行为数据（14万条）
docker-compose exec backend python -m app.services.data_import

# 导入知识图谱
docker-compose exec backend python -m app.services.kg_import

# 导入默认FAQ
docker-compose exec backend python -c "from app.services.import_service import import_default_faq; import asyncio; from app.core.database import async_session; asyncio.run(import_default_faq(async_session()))"
```

### 1.5 验证
```bash
# 健康检查
curl http://localhost:8000/health

# 运行测试
docker-compose exec backend python -m pytest tests/ -v --tb=short

# 准确率评测
docker-compose exec backend python -m pytest tests/test_accuracy_100.py -v
```

## 二、本地开发部署

### 2.1 后端
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 启动开发服务器
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2.2 前端
```bash
cd frontend
npm install
npm run dev  # 开发模式
npm run build  # 生产构建
```

### 2.3 Celery Worker
```bash
cd backend
celery -A app.tasks.celery_app worker --loglevel=info
```

## 三、常用运维命令

### 3.1 查看日志
```bash
docker-compose logs -f backend    # 后端日志
docker-compose logs -f celery-worker  # 异步任务日志
docker-compose logs -f postgres   # 数据库日志
```

### 3.2 重启服务
```bash
docker-compose restart backend
docker-compose restart celery-worker
```

### 3.3 数据库备份
```bash
docker-compose exec postgres pg_dump -U user lingshan > backup.sql
```

### 3.4 重新索引
```bash
docker-compose exec celery-worker python -c "
from app.tasks.index_task import reindex_all_documents
reindex_all_documents.delay()
"
```

## 四、性能调优

### 4.1 LLM 调用优化
- 多 API Key 轮询，避免单 Key 限流
- FAQ 白名单优先匹配（< 50ms）
- Redis 热点问题缓存（TTL 1小时）
- BGE-Reranker 精排提升检索质量

### 4.2 数据库优化
- PostgreSQL 连接池: 20-50
- Milvus 索引类型: IVF_FLAT
- Redis 缓存策略: LRU + TTL

### 4.3 前端优化
- Vite 代码分割
- 图片 WebP 格式
- Service Worker 离线缓存
- 路由懒加载
