# 时空穿越页面重构文档

> 移动端「时空穿越」页面 UI/UX 重构方案与实现记录  
> **版本**: v1.0 | **日期**: 2026-06-10

---

## 一、重构背景

### 1.1 原始问题

从 Web 版迁移到移动端时，时空穿越页面存在以下 UI/UX 问题：

| 问题 | 说明 | 影响 |
|------|------|------|
| Tab 栏过大 | 使用卡片式按钮，占用过多纵向空间 | 内容区域被压缩，信息密度低 |
| Emoji 作图标 | 🕐🔖 等 Emoji 作为结构性图标 | 跨平台不一致，视觉不专业 |
| 朝代筛选位置尴尬 | 筛选按钮挤在 Tab 下方，层级混乱 | 用户认知负担增加 |
| 内容区空洞 | 筛选栏下方大片空白 | 页面显得空洞，缺乏内容引导 |
| 视觉层级不清 | Header、Tab、筛选、内容之间缺乏节奏 | 整体观感松散 |
| 硬编码色值 | 组件中使用 `#22C55E` 等原始色值 | 与项目设计系统脱节 |

### 1.2 重构目标

- 紧凑、专业的移动端 UI，符合 iOS/Android 平台习惯
- 信息层级清晰：Header → Tab → 筛选 → 内容
- 使用项目语义色 token（`Colors.success/warning/error`）
- 所有触摸目标 ≥ 44pt，符合无障碍标准
- 消除 Emoji 作为结构性图标

### 2.2 分段式 Tab 栏

**设计决策**：使用 iOS 风格的分段控制器（Segmented Control），替代原来的大卡片按钮。

```
┌──────────────────────────────────┐
│ ──────┬──────┬──────┐           │
│ │时间线│解谜  │印章  │           │
│ ──────┘──────┴──────┘           │
│   ↑ 白色滑动指示器                  │
──────────────────────────────────┘
```

**实现要点**：
- 背景色：`Colors.gray100`（浅灰轨道）
- 指示器：白色圆角矩形 + 轻微阴影，使用 `Layout` 动画平滑滑动
- 文字：未选中 `Colors.gray500`，选中 `Colors.ink` + `fontWeight: 600`
- 高度：36pt，符合移动端紧凑设计
- 宽度：三等分，根据屏幕宽度动态计算

### 2.3 那年今日卡片

```
┌──────────────────────────────────┐
│ 那年今日              6/10       │  ← 标签 + 日期
│ 灵山某历史事件标题                 │  ← 标题（加粗）
│ 1234年前 · 事件描述内容...        │  ← 年份（高亮）+ 描述
──────────────────────────────────┘

**样式**：
- 左边框 3px `#C8882E`（赭石色，呼应东方美学）
- 白色卡片 + 轻微阴影
- 日期右上角对齐，小字号灰色

### 2.4 朝代筛选 Chip

```
[全部] [唐代] [宋代] [明代] [清代] [现代] →
```

**交互**：
- 默认选中"全部"（主题色填充）
- 点击朝代切换选中/取消（toggle）
- 选中时：背景色 = 朝代主题色 + 18% 透明度，边框 = 朝代主题色
- 横向滚动，无滚动条

### 2.5 时间线组件

#### 朝代分组标题

```
● ── 盛唐 ─────────────────────
```

- 左侧：10px 圆形色点（朝代主题色）
- 右侧：圆角矩形条，背景 = 朝代主题色 6% 透明度
- 文字：朝代简称（盛唐/大宋/大明...），加粗，朝代主题色
- 右侧渐变线填充剩余空间

#### 事件卡片

```
● ┌────────────────────────────
  │ 唐代              618      │  ← 朝代标签 + 年份
  │ 灵山建寺                    │  ← 事件标题（加粗）

**时间轴轨道**：
- 左侧 20px 宽轨道区域
- 8px 圆形色点（朝代主题色）

**事件卡片**：

## 六、技术实现要点

### 6.1 分段 Tab 栏实现

```typescript
// 动态计算每个 Tab 宽度
const tabWidth = (screenW - 28 * 2 - 8 * 2) / 3;

// 滑动指示器
<Animated.View
  layout={Layout.springify().damping(18).stiffness(200)}
  style={[
    styles.tabIndicator,
    {
      width: tabWidth,
      transform: [{
        translateX: TABS.findIndex((t) => t.key === activeTab) * (tabWidth + 8)
      }],
    },
  ]}
/>
```

### 6.2 时间线分组逻辑

```typescript
const grouped = useMemo(() => {
  const g: { era: string; events: TimelineEvent[] }[] = [];
  let lastEra = '';
  filtered.forEach((ev) => {
    if (ev.era !== lastEra) {
      g.push({ era: ev.era, events: [ev] });
      lastEra = ev.era;
    } else {
      g[g.length - 1].events.push(ev);
    }
  });
  return g;
}, [filtered]);
```

### 6.3 事件卡片全局索引计算

```typescript
// 用于 FadeInUp 延迟动画
const idx = grouped.slice(0, gIdx)
  .reduce((sum, g) => sum + g.events.length, 0) + eIdx;
```

## 八、后续优化方向

1. **虚拟列表**：事件超过 50 条时，使用 `FlashList` 替代 `ScrollView`
2. **骨架屏**：加载时使用 shimmer 效果替代 ActivityIndicator
3. **下拉刷新**：时间线支持 pull-to-refresh 更新数据
4. **分享功能**：那年今日卡片支持分享到微信/朋友圈
5. **离线缓存**：时间线数据本地缓存，离线可浏览
6. **深色模式**：适配系统深色模式，使用语义色 token
