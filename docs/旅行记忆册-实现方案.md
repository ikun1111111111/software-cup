# 旅行记忆册 (Travel Memory Book) — 实现方案

## 设计理念

参考 [TrailSnap (行影集)](https://github.com/LC044/TrailSnap) 的核心理念：

> 把旅行从"拍过"变成"可回味、可分享、可沉淀"。

TrailSnap 的关键能力：
- 智能识别相册中的车票、门票，自动记录行程
- 自动整理出适合发朋友圈的照片，甚至准备好文案
- 生成 15 秒短视频回忆
- 每个人拥有自己的 AI 数据中心，相册是核心数据来源

我们的项目在此基础上，结合 **AI 数字人对话** 的独特优势：
- 不需要游客手动拍照 — 对话记录本身就是旅行数据
- AI 导游讲解的内容自动转化为旅行记忆
- 数字人可以主动引导游客记录（"要不要帮你记下这一刻？"）

## 核心流程

```
游客与AI对话/扫码景点/参观路线
        ↓ (数据自动采集)
  ┌─────────────────────────────────────┐
  │         AI 数据中心 (记忆库)          │
  │  对话精华 │ 景点打卡 │ 路线轨迹 │ 情绪  │
  └─────────────────────────────────────┘
        ↓ (一键生成)
  ┌──────────────┬──────────────┬──────────────┐
  │  单条记忆卡  │  旅程回忆录  │  分享卡片    │
  │  AI润色文案  │  AI总结全文  │  一键导出PNG │
  └──────────────┴──────────────┴──────────────┘
```

## 功能清单

### F1: 自动记忆采集 (数据来源)
从以下场景自动创建记忆条目：
- 游客在 ChatPage 与 AI 对话中提及的景点
- 游客通过 VisionPage 扫码识别的景点
- 游客通过 RecommendPage 走完的路线
- 关键对话（首次问某个景点、表达情感的语句）

### F2: 记忆册浏览
- 时间线形式展示所有记忆
- 每条记忆：标题 + 文案 + 景点标签 + 情绪标签 + 时间
- 支持按景点/日期筛选

### F3: AI 润色 (单条)
- 原始记录："今天去了灵山大佛，很高很壮观"
- AI 润色后："拾级而上，仰望八十八米青铜大佛，梵音入耳，心生敬畏。此刻方知，何为'山不在高，有仙则灵'。"
- 保留原文对照，游客可切换查看

### F4: 一键旅程总结
- AI 汇总所有记忆，生成一篇完整的旅行游记
- 包含：行程概览、亮点景点、情感变化、推荐语
- 适合发朋友圈/小红书的长文

### F5: 分享卡片导出
- 精美图片卡片：水墨风格 + 宣纸纹理 + 禅意排版
- 内容：标题 + 文案 + 景点列表 + 日期 + 灵山胜境标识
- 导出为 PNG，保存到相册或分享到微信

## 实现步骤

### Step 1: 后端数据模型 — `backend/app/models/memory.py`

```python
class TravelMemory(Base):
    """单条旅行记忆"""
    __tablename__ = "travel_memories"
    id: int                          # 主键
    session_id: str                   # 关联游客会话
    title: str                        # 记忆标题 (如"初见灵山大佛")
    original_content: str             # 原始内容 (从对话提取)
    polished_content: str | None      # AI润色后的内容
    spot_name: str | None             # 关联景点名称
    spot_id: str | None               # 关联景点ID
    source_type: str                  # 来源: chat / vision / route
    mood_tag: str | None              # 情绪标签: 敬畏/惊喜/平静/感动
    metadata_json: dict | None        # 扩展数据 (对话ID、图片URL等)
    created_at: datetime
    updated_at: datetime

class JourneySummary(Base):
    """旅程总结"""
    __tablename__ = "journey_summaries"
    id: int
    session_id: str
    title: str                        # 如"灵山胜境一日游记"
    content: str                      # AI生成的完整游记
    spot_count: int                   # 涉及景点数
    memory_count: int                 # 包含记忆条数
    date_range: str                   # 如"2026-06-08"
    cover_image_url: str | None       # 封面图
    created_at: datetime
```

### Step 2: 后端记忆服务 — `backend/app/services/memory_service.py`

核心函数：
- `extract_memories_from_chat(session_id)` — 从 interaction_logs 提取记忆
- `polish_memory(memory_id)` — AI 润色单条记忆
- `generate_journey_summary(session_id)` — 生成旅程总结

复用：`app.core.llm_router.route()` 调用 LLM，`app.core.redis_client` 缓存

### Step 3: 后端 API — `backend/app/api/memory.py`

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/memory/list?session_id=xxx` | GET | 获取所有记忆 |
| `/api/memory/generate` | POST | 从对话记录自动生成记忆 |
| `/api/memory/{id}/polish` | POST | AI 润色单条 |
| `/api/memory/summary/generate` | POST | 生成旅程总结 |
| `/api/memory/summary/latest?session_id=xxx` | GET | 获取最新总结 |
