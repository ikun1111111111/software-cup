# VRM 数字人表现包 Demo — 演示脚本与验收清单

## 访问路径
`我的` → 菜单第一项「数字人表现包 Demo」→ 进入 `/vrm-performance-demo`

## 页面结构
- 顶部：标题 + 返回按钮
- 中部：全屏 VRM 舞台（mode=full）+ 字幕气泡
- 状态面板：实时显示表情、动作、口型值、说话状态
- 表现包按钮：8 个场景，点击即播放
- 控制栏：停止播放、减少动效开关、循环播放开关

## 演示脚本（3 分钟）

1. **入场（0:00）**：进入 Demo 页，小灵以 neutral 待机，眨眼呼吸自然。
2. **欢迎（0:10）**：点「欢迎」，小灵微笑 + 挥手 + 语音播报欢迎语。
3. **倾听（0:20）**：点「倾听」，小灵歪头 + 放松表情，说"我在听"。
4. **思考（0:30）**：点「思考」，小灵思考表情 + 头部偏左，说"我来帮你整理"。
5. **推荐路线（0:40）**：点「推荐路线」，小灵指向 + 开心，说"这条路线适合一小时"。
6. **到点讲解（0:55）**：点「到点讲解」，小灵点头 + 放松，说"这一站我们来到灵山大佛"。
7. **惊叹（1:15）**：点「惊叹介绍」，小灵惊讶 + 抬头，说"高达八十八米，非常震撼"。
8. **未知问题（1:30）**：点「未知问题」，小灵悲伤 + 摇头 + 低头，说"不能随便编造"。
9. **完成总结（1:45）**：点「完成总结」，小灵感激 + 鞠躬，说"帮你生成旅行记忆"。
10. **停止（2:00）**：点「停止播放」，字幕/口型/动作/表情全部复位到 neutral。
11. **减少动效（2:10）**：开启「减少动效」，重新点「欢迎」，大动作被跳过，仅保留表情和语音。
12. **循环播放（2:25）**：开启「循环」，点任意表现包，自动重复播放直到停止。

## 验收清单

### 表现验收
- [ ] 8 个表现包按钮均可点击，每个触发不同表情 + 动作 + 语音
- [ ] 欢迎、推荐路线、到点讲解、未知问题、完成总结 5 个场景表现稳定可辨认
- [ ] 表情切换不突兀，动作结束后回到自然 idle
- [ ] 字幕与语音同步出现
- [ ] 口型随语音变化，语音结束后口型闭合

### 注视验收
- [ ] 「思考」时头部明显偏左
- [ ] 「惊叹介绍」时头部明显抬头
- [ ] 「未知问题」时头部明显低头
- [ ] 「推荐路线」时头部微偏看向路线卡片方向

### 控制验收
- [ ] 点「停止播放」后，字幕、口型、动作、表情全部复位
- [ ] 开启「减少动效」后，wave/point/clap/bow 等大动作被跳过
- [ ] 开启「循环播放」后，当前表现包播完后自动重播
- [ ] 关闭「循环播放」后，不再自动重播

### 状态面板验收
- [ ] 表情栏实时显示当前 Emotion 值
- [ ] 动作栏实时显示当前 Action 值
- [ ] 口型栏实时显示 0-1 数值
- [ ] 说话栏在播报时显示「是」，结束后显示「否」

## 技术实现说明

- 页面使用 `useDigitalHumanDriver('tts')` 作为唯一驱动入口
- `VRMView mode="full"` 渲染全屏 3D 数字人
- 路由 `/vrm-performance-demo` 已加入浮窗隐藏列表，不会出现重复 VRM
- 表现包数据定义在 `constants/vrmPerformancePresets.ts`，可独立调参
- `GazeTarget` 通过 `headRotation` 映射到头部旋转角度
