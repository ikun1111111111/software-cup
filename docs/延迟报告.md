## 优化建议

1. **LLM 调用优化**
   - 多 API Key 轮询避免单 Key 限流
   - FAQ 白名单优先匹配（< 50ms 内命中）
   - Redis 缓存热点问答（TTL 1小时）
   - 流式输出减少感知延迟

2. **RAG 检索优化**
   - Milvus IVF_FLAT 索引
   - BM25 并行查询
   - Reranker Top-10 精排

3. **WebSocket 优化**
   - 心跳间隔 30s
   - 房间 TTL 2 小时自动过期
   - Redis Pub/Sub 多实例广播
