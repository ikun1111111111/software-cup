# 灵山智慧导览登录注册页润色与鉴权修复设计

## 目标

提升移动端登录、注册页面的视觉完成度和交互可靠性，同时修复登录失败返回 401 时被全局鉴权逻辑误判为会话过期的问题。

## 范围

- `software/mobile/app/auth/login.tsx`
- `software/mobile/app/auth/register.tsx`
- 登录注册共用 UI 组件与表单校验逻辑
- `software/mobile/api/request.ts` 的 401 分类处理
- 相关 Jest 测试

不包含第三方登录、短信验证码、找回密码和后端账号体系重构。

## 视觉方向

采用“宣纸雅致”的灵山文旅风格：

- 宣纸白作为页面底色，墨色作为主要文字和主操作色。
- 暖金用于品牌印章、细节强调和轻量装饰，不大面积铺色。
- 通过留白、细边框、柔和阴影和淡山水纹理建立层次，避免厚重卡片堆叠。
- 登录与注册保持统一品牌头部、输入控件、按钮、错误提示和页面节奏。
- 所有正文和字段提示保持清晰对比度，交互目标不小于 44 像素。

## 页面结构

### 登录页

1. 品牌区域：灵山印章、产品名和一句简短价值文案。
2. 欢迎区域：标题“欢迎回来”和旅程延续说明。
3. 登录表单：用户名、密码、密码显示切换。
4. 状态反馈：字段错误、接口错误、加载状态。
5. 主操作：“登录并继续旅程”。
6. 次操作：创建账号、游客进入。

### 注册页

1. 简洁返回入口和品牌标题。
2. 注册价值说明，突出路线、回忆和偏好同步。
3. 用户名、昵称、密码、确认密码字段。
4. 密码强度与规则提示。
5. 主操作：“创建账号并开启旅程”。
6. 已有账号的登录入口。

## 功能与数据流

### 登录

1. 用户输入用户名和密码。
2. 前端先校验必填项并阻止重复提交。
3. 调用 `POST /api/auth/login`。
4. 成功后保存 Token、刷新内存 Token 缓存、写入用户状态并进入首页。
5. 登录接口返回 401 时，仅在当前表单展示“用户名或密码错误”，不触发全局未授权跳转。

### 注册

1. 前端校验用户名格式、昵称长度、密码长度和两次密码一致性。
2. 调用 `POST /api/auth/register`。
3. 成功后保存接口返回的 Token 和用户信息，自动进入首页。
4. 用户名已存在等业务错误显示在表单区域，并在用户修改相应字段后清除。

## 401 分类处理

全局响应拦截器不能只依据 HTTP 状态码判断是否需要退出登录。

- 登录、注册等公开鉴权接口的 401 属于业务失败，只转换为可展示错误，不清理会话、不触发路由跳转。
- 携带 Bearer Token 的受保护请求返回 401 时，才清理 Token、失效缓存并发出全局未授权事件。
- 无 Token 的普通公开请求即使返回 401，也不得触发全局退出逻辑。

该规则避免错误账号密码造成登录页重复跳转，同时保留真正 Token 失效时的统一退出能力。

## 组件边界

- `AuthScreenShell`：页面安全区域、背景装饰、滚动与键盘避让。
- `AuthBrandHeader`：品牌印章、标题和说明文案。
- `AuthField`：标签、输入框、前置图标、密码切换、错误文本。
- `AuthSubmitButton`：按压、禁用和加载状态。
- 表单校验函数保持为可独立测试的纯函数。

组件只负责展示和局部交互；API 调用、Token 持久化和路由跳转继续由现有鉴权 Hook 与页面流程负责。

## 错误与交互状态

- 字段错误紧邻字段展示，不仅在页面顶部汇总。
- 服务端错误使用带图标的提示区域，并保留服务端可读错误信息。
- 用户开始修改相关字段时清除对应错误。
- 请求期间禁用主按钮并显示加载指示，防止重复提交。
- 密码显示切换具备可访问标签，不使用不可识别的字符代替图标。
- 键盘提交触发与主按钮相同的校验和提交逻辑。

## 测试策略

### 单元测试

- 登录必填校验。
- 注册用户名格式、密码长度、确认密码一致性。
- 密码强度计算。
- 公开登录请求返回 401 时不触发全局未授权事件。
- 带 Token 的受保护请求返回 401 时清 Token 并触发事件。

### 页面行为测试

- 加载时按钮不可重复提交。
- 修改字段后对应错误被清除。
- 登录、注册成功后保存状态并导航至首页。
- 错误账号密码留在登录页并显示明确提示。

### 验证

- 执行相关 Jest 测试和完整移动端测试。
- 执行 TypeScript 类型检查。
- 在 Web 和窄屏移动尺寸检查布局、键盘、焦点、错误态和加载态。

## 完成标准

- 错误账号密码产生的 401 不再触发全局登录跳转。
- 登录和注册主流程可用，错误信息明确，提交不会重复触发。
- 两个页面具有一致、精致的灵山文旅视觉语言。
- 核心校验与鉴权分支具有自动化回归测试。
- 测试和类型检查通过，且不引入当前任务范围外的代码改动。
