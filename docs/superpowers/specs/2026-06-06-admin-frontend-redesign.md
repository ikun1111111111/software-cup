# Admin 前端重构设计文档 — 青绿山水长卷

## 目标

根治 Admin 后台"卡片平铺堆叠"的 AI 味，将 Dashboard / Report / Knowledge / Avatar 四大页面重新设计为**一幅横向展开的《千里江山图》长卷**。数据不再是孤立的卡片，而是山水间的题跋、印章、楼阁与烟火。

---

## 视觉方向

### 核心隐喻

| 界面元素 | 山水隐喻 |
|---------|---------|
| 页面背景 | 青绿山水长卷底色（石青、石绿渐变 + 淡墨皴纹） |
| KPI 大字 | 画幅顶部的朱红鉴藏印 |
| 折线/柱状图 | 一笔勾勒的山脊线 / 层叠的山峦 |
| 实时监控区 | 近水楼阁（精巧、半透明，有"人在画中"感） |
| 热点问题列表 | 林间题跋（竖排或斜排的小字批注） |
| 热力图 | 市井烟火 / 山间灯火 |
| 玻璃态卡片 | 彻底移除，改为"宣纸质感"或"绢本质感"的实色面 |
| 留白区域 | 长卷中的云雾/水面，不是空，是意境 |

### 配色方案

放弃现有玻璃态的冷灰/蓝紫，全面转向**中国传统矿物颜料色谱**：

```
--mountain-deep:    #1B4D3E   (石绿深处，用于重色背景)
--mountain-mid:     #4A7C6F   (青绿主体，用于图表主色)
--mountain-light:   #8FB8AA   (远山淡影，用于次要信息)
--sky-dawn:         #E8DCC4   (绢本底色，页面基底)
--sky-mist:         #C9D5D1   (云雾灰绿，分割线/边框)
--ink-dark:         #2A2520   (浓墨，主文字)
--ink-medium:       #5C534A   (淡墨，次要文字)
--vermilion:        #C84B31   (朱砂，KPI/印章/强调)
--gold-leaf:        #C9A96E   (泥金，hover 光晕/图标)
--paper-texture:    #F3EFE6   (宣纸白，内容面板底色，带 3% 噪点纹理)
```

### 字体方案

| 层级 | 字体 | 用途 |
|------|------|------|
| 展示标题 | `Noto Serif SC` (思源宋体) / `Source Han Serif CN` | 页面大标题、KPI 数字、印章文字 |
| 正文/数据 | `Noto Sans SC` (思源黑体) | 列表、标签、说明文字 |
| 等宽数据 | `JetBrains Mono` / `Roboto Mono` | 时间、百分比、坐标 |
| 装饰批注 | `ZCOOL XiaoWei` (站酷小薇体，手写感) | 热点问题列表、题跋式批注 |

## 布局架构

### 全局改动

1. **移除玻璃态** (`GlassCard` 组件样式全面替换)
2. **移除底部 Dock** (`DockNav.tsx` 改为左侧垂直卷轴导航)
3. **背景层**：全屏固定 `div`，CSS 渐变模拟青绿山水底色 + SVG 噪点纹理 + 底部淡墨山峦轮廓线
4. **页面过渡**：从淡入淡出改为"画卷徐徐展开"（clip-path 从左到右揭示）

### 左侧导航（卷轴式）

- 位置：左侧固定，宽度 72px（收起）/ 200px（展开）
- 样式：像画卷的装裱边，深墨底色，图标是**白描线条风格**（非填充）
-  active 状态：图标下方有一道朱红竖线，像批注的朱笔点校
- hover：图标轻微右移 + 淡金色光晕

### Dashboard 页面重构

**纵向分区改为"长卷段落"：**

```
┌──────────────────────────────────────────────────────────────┐
│  [左侧导航]                                                   │
│                                                              │
```

**关键设计细节：**
- **KPI 区**：数字用 `Noto Serif SC` 粗体，字号 48px，颜色 `vermilion`。数字下方不是卡片，而是像印章一样有一个 1px 的细边框（`ink-medium`），四角有极小的装饰折角（像裱画的角签）。
- **实时监控**：背景是 `paper-texture` 色，没有圆角。四个指标排成 2×2，但格子之间用 1px 的 `sky-mist` 细线分隔，像窗格。连接状态的小圆点改为一个**呼吸灯式的朱砂红点**。
- **热点问题**：放弃现在的列表卡片。每个问题是一条**横向的题跋**——左侧是数字序号（`ZCOOL XiaoWei` 手写体），中间是问题文字（`Noto Sans SC`），右侧是次数（朱红色小圆圈里写数字，像批注的圈点）。hover 时整行像被朱砂笔轻轻划过，出现淡红色的下划线。
- **热力图**：ECharts 热力图的颜色映射改为从**石青（低）→ 石绿（中）→ 朱砂（高）**，网格线用淡墨。标题不是普通的 h3，而是像画上的题款，左侧有一条竖线引注。

### Report 页面重构

- **顶部报告摘要**：不再是 `GlassCard` 包裹的 Markdown。改为一块**展开的卷轴**——顶部和底部有深色的卷轴轴头装饰，中间是 `paper-texture` 底色，文字像写在宣纸上。
- **情感趋势图**：折线颜色改为石绿（positive）、淡墨（neutral）、朱砂（negative）。线的平滑度降低， slightly more angular，像山水画的皴法线条。面积填充改为水墨晕染效果（ECharts 渐变透明度从 0.3 到 0）。
- **词云**：不使用 echarts-wordcloud。改为**印章集合**——每个关键词是一个不同大小的方形/圆形印章，文字是反白的（白字在红/绿底色上），像画上的收藏印。大小反映频次，点击时有"盖印"的按压动效。
- **盲区发现 & 服务建议**：改为两列**竖排题跋**。左侧标题旁有一个小小的朱砂圆点，列表项是手写体批注。

### Knowledge 页面重构

- **文档列表**：放弃现在的卡片 hover 效果。每个文档像画卷中的一页**经折装**——左侧有像折页一样的竖线装饰，状态标签改为小小的印章（"已索引"=绿色小印，"处理中"=黄色小印）。
- **FAQ 列表**：FAQ 条目像**碑帖上的文字**，问题用宋体，答案用淡墨细字。点击展开时有像打开折页的动画。
- **上传区**：拖放区域改为一张**空白的宣纸**，拖入文件时宣纸上出现淡墨的晕染，然后逐渐显现出文字（文件名）。

### Avatar 页面重构

- **左侧预览区**：数字人预览框改为**扇面形**或**圆形月洞门**（CSS `clip-path`）。框外有像画框一样的细线装饰。
- **右侧配置区**：Tabs（外观/声音/欢迎语）改为像**琴键**一样的窄条，active 的 tab 有朱砂色的小圆点。
- **保存按钮**：改为一个**红色印泥按钮**——矩形，深朱砂底色，hover 时有像按印章一样的轻微下压 + 泥金边缘发光。

## 动效系统

### 页面级

- **卷轴展开**：页面加载时，内容从 `clip-path: inset(0 100% 0 0)` 渐变到 `inset(0 0% 0 0)`，像画卷从左到右徐徐展开，持续时间 800ms，ease-out。
- **云雾淡入**：背景的山峦轮廓在页面加载后 300ms 才开始淡入，像雾气散去。

### 组件级

- **印章盖印（KPI/按钮）**：hover 时，`transform: scale(0.98)` + `box-shadow` 从外扩变为内缩，像印章按下去。
- **朱笔圈点（列表 hover）**：hover 时，一条 2px 的 `vermilion` 下划线从 `scaleX(0)` 动画到 `scaleX(1)`，transform-origin 从左侧开始。
- **水墨晕染（图表/数字变化）**：数字变化时，旧数字像被水晕开一样淡出（`filter: blur(4px)` + `opacity: 0`），新数字从清晰状态淡入。
- **题跋出现（列表加载）**：列表项 stagger 入场，每个延迟 50ms，从 `opacity: 0, translateX(-10px)` 到正常状态，像一笔一划写出。

## 验收标准

1. 打开 Dashboard，第一眼感受是"像在看一幅画"而不是"一堆数据卡片"
2. 玻璃态 `backdrop-filter: blur` 在 admin 区域完全消失
3. 所有图表（折线、柱状、热力图、词云）都使用青绿/朱砂/淡墨配色
4.  hover 动效不是普通的 scale/shadow，而是有"盖印""圈点""晕染"等文化意象
5. 页面加载时有卷轴展开或云雾淡入的入场动画
6. 移动端至少保持功能可用（布局可退化为纵向流，但保留颜色字体风格）
