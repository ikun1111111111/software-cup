色彩系统：时间主题与强调色

"沉浸式意境"的核心是随时间流动的背景，先确定默认色板和点缀色

A

晨雾 Dawn — 默认主题

背景：淡青灰 → 暖金渐变

  • 氛围：清新、希望、一天的开始
  • 文字色：深褐（#3d352e）保证可读性
  • 卡片：半透明白色（rgba(255,255,255,0.72)）+ 微阴影
B

白昼 Day — 默认主题

背景：天空蓝 → 云白渐变

  • 氛围：明亮、开阔、通透
  • 文字色：炭黑（#1a1a1a）高对比
  • 卡片：纯白（#ffffff）+ 淡蓝边框
C

日暮 Dusk — 默认主题

背景：橙红 → 紫粉渐变

  • 氛围：温暖、感性、一天中最美的时刻
  • 文字色：深紫褐（#3e2b36）柔和不刺眼
  • 卡片：暖白（rgba(255,250,245,0.78)）+ 金粉高光
D

月夜 Night — 默认主题

背景：深蓝 → 墨黑渐变

  • 氛围：静谧、深邃、专注
  • 文字色：月白（#e6edf3）降低蓝光伤害
  • 卡片：深蓝灰玻璃（rgba(30,40,55,0.65)）+ 冷色边框

💡 提示：四种主题会随系统时间自动切换（6-10点晨雾 / 10-16点白昼 / 16-19点日暮 / 19-6点月夜），这里选的是首次加载的默认主题。
