## 一、项目概述

### 1.1 项目背景

针对智慧旅游场景，构建一个基于大模型和多模态技术的数字人导览系统。游客可通过语音或文字与数字人交互，获取景区讲解、路线推荐等服务；管理方可维护知识库、配置数字人形象、查看运营数据分析报告。

### 1.2 核心目标

| 指标 | 目标值 |
|------|--------|
| 事实性问答准确率 | ≥ 90%（基于标准测试集） |
| 语音交互端到端延迟 | < 5 秒 |
| 数字人表现 | 口型同步、表情配合 |
| 系统稳定性 | 无崩溃或长时间无响应 |

### 1.3 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript + Vite | 构建速度快，生态成熟 |
| UI 组件库 | Ant Design 5（管理端）+ 自定义样式（游客端） | 管理端标准化，游客端个性化 |
| 数字人渲染 | Live2D Cubism SDK + pixi-live2d-display | 2D 数字人驱动，口型表情 |
| 后端框架 | Python 3.11 + FastAPI | 异步支持好，AI 生态无缝衔接 |
| LLM 主模型 | DeepSeek-V3 API | 中文能力强，成本低 |
| LLM 视觉 | Qwen-VL-Max | 拍照识景点 |
| LLM 情感/校验 | 豆包 Lite API | 免费额度大 |
| ASR | faster-whisper (medium) | 开源，中文识别优秀 |
| TTS | CosyVoice | 阿里开源，中文自然度最佳 |
| Embedding | BGE-M3 (BAAI) | 中文向量化效果最好 |
| Reranker | BGE-Reranker-v2-m3 | 检索精排 |
| 向量数据库 | Milvus | 支持混合检索 |
| 关系数据库 | PostgreSQL 16 | 成熟稳定 |
| 缓存 | Redis 7 | 热点问答缓存、Celery 队列 |
| 对象存储 | MinIO | 自建 S3 兼容存储 |
| 任务队列 | Celery + Redis | 文档索引等异步任务 |
| 实时通信 | WebSocket + SSE | 双向通信 + 流式输出 |
| 可视化 | ECharts 5 | 数据大屏图表 |
