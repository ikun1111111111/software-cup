# VRM 数字人导览系统 - 测试用例

## 测试环境

- 设备：移动端（iOS/Android）
- 框架：Expo / React Native
- 浏览器：Chrome（Web 模式）
- 测试页面：`/guide-demo`

## 二、动作测试用例

### 2.1 头部动作

| 用例ID | 动作 | 预期效果 | 测试方法 |
|--------|------|----------|----------|
| A001 | nod (点头) | 头部上下点头，幅度约7° | 点击"点头"按钮 |
| A002 | shakeHead (摇头) | 头部左右摇头，幅度约11° | 点击"摇头"按钮 |
| A003 | tiltHead (歪头) | 头部左右倾斜 | 点击"歪头"按钮 |
| A004 | lookUp (抬头) | 头部向右上方抬起，平滑过渡 | 点击"抬头"按钮 |
| A005 | lookDown (低头) | 头部向下低 | 点击"低头"按钮 |

### 2.2 手势动作

| 用例ID | 动作 | 预期效果 | 测试方法 |
|--------|------|----------|----------|
| A006 | wave (挥手) | 右手抬起，手掌左右摆动 | 点击"挥手"按钮 |
| A007 | point (指向) | 右手前伸，食指伸出，其余握拳 | 点击"指向"按钮 |
| A008 | clap (鼓掌) | 双手合十拍击 | 点击"鼓掌"按钮 |
| A009 | bow (鞠躬) | 头部、脊柱、整体前倾 | 点击"鞠躬"按钮 |

### 2.3 动作恢复

| 用例ID | 测试场景 | 预期效果 |
|--------|----------|----------|
| A010 | lookUp 结束后恢复 | 300ms 平滑过渡回中立姿态 |
| A011 | lookUp 进行中触发新动作 | 立即结束恢复，执行新动作 |
| A012 | 动作进行中切换其他动作 | 新动作立即生效 |
| A013 | 动作结束后回到 idle | 恢复呼吸、眨眼等 idle 动画 |

## 测试执行说明

### 执行步骤

1. 启动移动端应用
2. 进入 `/guide-demo` 测试页面
3. 按顺序执行上述测试用例
4. 记录每个用例的实际结果
5. 标记通过/失败
